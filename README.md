## Installation :

Pour installer le projet, il faut au préalable avoir installé Docker.

Cloner le repo pour récupérer le code source.
`git clone https://github.com/Ewen-crvs/whiteboard-vite-react.git`

Aller dans le dossier.
`cd whiteboard-vite-react`

Exécuter le Dockerfile pour lancer le serveur back et front.
`docker compose up --build -d`

## Technologies :

Projet fait avec Vite et React.
On a utilisé Konvas.JS pour faire bouger les formes à la main.
